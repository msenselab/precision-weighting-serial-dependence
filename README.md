# Precision weighting and serial dependence under uncertainty

Public analysis code, cleaned data, model outputs, and manuscript figures for the
serial-dependence uncertainty project.

## Quick start

Install the project dependencies with [uv](https://docs.astral.sh/uv/):

```bash
uv sync
```

Reproduce the behavioral analyses and validate the included Kalman-model results:

```bash
uv run python code/02_behavior_results.py
uv run python code/04_validate_kalman.py
```

The canonical manuscript figures are included in `figures/`. To regenerate and
verify the non-schematic figures:

```bash
uv run python code/05_plot_behavior.py   # Figures 2, 3, 4, A1
uv run python code/06_plot_kalman.py     # Figures 6, 7, B1, B2
```

Run the lightweight public-repository checks with:

```bash
uv sync --extra dev
uv run pytest
```

Figures 1 and 5 are static schematics and are not generated by these scripts.
The scripts render into temporary staging directories and replace tracked
exports only when the rendered PNG dimensions or pixels change.

## Repository layout

```text
data/       Cleaned trial-level data
code/       Numbered analysis and plotting entry scripts
models/     Three-state Kalman model implementation
plotting/   Shared figure-generation code and plotting style
notebooks/  Kalman analysis notebook
results/    Canonical output tables and model checks
figures/    Final manuscript figures
```

The behavioral analysis scripts load these files directly.

## Reproducibility notes

- `code/01_preprocess.py` documents preprocessing but requires the original raw
  experiment CSV folders, which are not included.
- Full Kalman-model fitting is computationally expensive and is not required for
  the public reproduction workflow. `code/03_fit_kalman.py` is retained as
  methodological source code.
- Canonical fit outputs and posterior-predictive checks are included in
  `results/kalman_model_fits/` and `results/kalman_model_checks/`.
- `notebooks/kalman.ipynb` reads the included results by default. Set
  `REFIT = True` in the notebook to fit a new checkpointed model grid and
  regenerate validation outputs under `results/kalman_refit/`.
- The exports in `figures/` are the authoritative manuscript figures. Plotting
  scripts verify presentation-level reproduction while preserving canonical
  files when only PNG compression or PDF metadata differs.
- This is an analysis repository rather than an installable Python package. Use
  `uv sync` and `uv run`; `uv build` is not supported.

## Main outputs

- `results/figure_source_data/`: compact figure source-data tables
- `results/kalman_model_fits/`: model fits, rankings, and parameter summaries
- `results/kalman_model_checks/`: posterior-predictive and recovery checks
- `figures/`: canonical manuscript figure exports
